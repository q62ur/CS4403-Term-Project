# CS4403 – Term Project

## Can AI Simulate Reality?
### A Data Mining Study of Generated vs Authentic Datasets

This repository is for the CS4403 Data Mining term project.

The goal of this project is to investigate whether AI-generated datasets can realistically simulate authentic, real-world datasets. Using data mining techniques, we will compare generated and real datasets to analyze similarities and differences in statistical properties, patterns and predictive usefulness.

This repository will be updated throughout the term with datasets, analysis code and reports as the project progresses.
